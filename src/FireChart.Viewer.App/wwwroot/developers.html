Embed it in your application

The Viewer is a web application of its own shown in an iframe. Your page needs one ES module, the SDK: it creates the frame, gives it the configuration and turns its messages into events and promises. No framework, no build step.

Try it with this copy

Save this as a file and open it from a local web server. This copy of the Viewer accepts commands from its own pages only, so run your own copy for a page of another origin (below).

Run your own copy

The Docker image serves this whole site. host.json lists the origins of the pages that may embed it.

docker run -d -p 8080:8080 \
  -v "$PWD/host.json:/usr/share/nginx/html/host.json:ro" \
  ghcr.io/firechart/viewer:latest
{ "frameAncestors": ["'self'", "https://app.example.org"] }

Or copy the folder of the site to any static web server: every address in it is relative.
